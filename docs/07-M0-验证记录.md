# M0 验证记录

日期：2026-09-27；环境：Ubuntu 24.04、Node.js 24.15、Rust 1.98、WebKitGTK 4.1 开发库。所有用户数据流程测试均在临时目录运行。

| 检查 | 结果 |
| --- | --- |
| `npm run build` | TypeScript 检查和 Vite 生产前端构建通过 |
| `cargo check` | Tauri/Rust/SQLCipher 编译检查通过 |
| `cargo test --lib` | 2 项通过：建库→锁定→新实例解锁，错误密码拒绝；备份预览和恢复；损坏备份不覆盖当前库 |
| 磁盘与权限 | 测试数据库不含 SQLite 明文头或测试敏感文本；元数据和备份也不含测试敏感文本；目录为 `0700`，数据库和备份为 `0600` |
| `npm run tauri dev` | 在隔离的 `XDG_DATA_HOME` 下启动开发桌面进程，无 Tauri 前后端版本警告 |
| `npm run tauri build -- --no-bundle` | 生产前端与 Rust 二进制构建通过；未打包安装文件 |
| 布局 | 开发专用界面夹具在 720×700 与 900×700 检查；文档横向宽度分别为 705 和 885，均没有横向滚动；导航在窄屏折叠 |
| 键盘 | `Tab` 到“下一步”，`Enter` 进入目标选择，`Space` 选中复选框；主导航 `Tab` 和 `Enter` 可进入记录空态 |

尚需真实安装包和干净 Ubuntu 机器上的端到端验证：WebKitGTK 动态依赖、安装后文件位置、窗口管理器缩略图、屏幕阅读器、断电/磁盘满恢复与长期大库性能。UI 夹具没有使用真实密码或真实库。测试中的源代码示例字符串不是产品数据。

引导页最后增加了步骤切换后的标题焦点。此改动已通过 TypeScript 与生产前端构建；此前的键盘检查在此改动前完成。复测所需的本地服务启动被自动审批的账户用量限制中止，静态文件页面也被浏览器 URL 策略拒绝，因此这一步的交互复测尚未完成。
