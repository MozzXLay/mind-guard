# 净界｜全页面 UI 设计与交互规范

版本：v0.1 · 与 `04-可交互UI原型.html` 对照使用。原型中的数字和内容均为演示数据，不保存真实敏感记录。

## 1. 视觉方向

关键词：安静、克制、有温度、可信。选用深色墨绿主界面、偏暖白文字、浅鼠尾草绿作积极动作和低饱和琥珀色作提醒。避免健康类产品常见的白底信息墙、勋章轰炸、红色“失败”警报。大面积呼吸空间通过层级、字形和少量曲线形成节奏，不靠堆色块。支持同等层级的浅色主题，不以颜色单独表达状态。

| Token | 深色示例 | 用途 |
| --- | --- | --- |
| `--bg` | `#101915` | 应用背景 |
| `--sidebar` | `#131d18` | 导航区域 |
| `--surface` | `#1a2720` | 内容卡片 |
| `--surface-2` | `#23332a` | 悬浮/选中 |
| `--text` | `#eff2e9` | 主要文字 |
| `--muted` | `#9dad9e` | 次要说明 |
| `--line` | `#314137` | 分隔 |
| `--accent` | `#add4b0` | 主要按钮/高亮 |
| `--warning` | `#dec38d` | 非阻断提醒 |

字型优先系统中文字体 `Noto Sans CJK SC / Microsoft YaHei / sans-serif`；数字可用系统等宽字体。主标题 28–36px、页面标题 24px、卡片标题 16px、正文 14–16px、辅助 12–13px；最小正文 12px。间距采用 4/8/12/16/24/32/48，控件触控区域至少 40px。卡片圆角 16–22px，按钮 10–12px。桌面布局以 1440×900 为主要验收视口；支持 900×700 与 720×700，无横向滚动。

## 2. 全局框架

左侧导航宽 218px：品牌、今日、记录、SOS、计划、洞察、日记、屏蔽；底部设置与状态。右侧：顶部页面标题、状态提示、锁定快捷入口；主要内容最大宽 1180px。当前页以底色和竖向小标记明确表示。SOS 是独立高优先级入口，但不闪烁。页面切换保留导航，锁定页覆盖并遮蔽其内容。

页面路径可按 `/today`, `/records`, `/sos`, `/plan`, `/insights`, `/journal`, `/blocker`, `/settings`；引导与锁定是全局状态而非直接可访问的敏感路由。原型提供“引导”“锁定”“拦截页”的预览入口，正式产品不展示调试入口。

## 3. 页面逐项设计

### U01 首次引导

三步：欢迎与隐私 → 选择目标（可多选，也可稍后设置）→ 创建密码。每步上方有 1/3 进度；底部主按钮始终清晰。密码步骤提供明文/隐藏、强度提示与恢复限制；不默认勾选开机启动、提醒、遥测或性行为记录。

### U02 今日

顶部一句可变问候语与日期；主卡左侧“今天先做一件小事”，右侧可进入 SOS。下方三块：本周记录概况、当前计划行动、最近记录。统计写明“示例数据 / 过去 7 天”，不展示诊断、精气/康复百分比或固定禁欲倒计时。空态显示一个可执行动作「记下第一次观察」。

### U03 新建记录弹窗

居中弹窗，宽 560px，事件单选呈分段控件；时间、强度 0–10、触发因素、多行备注按重要度排列。底部「取消」「保存记录」；保存后在记录历史可编辑、撤销。类型“自慰”不带失败样式。Escape 关闭；关闭前已修改表单需明确放弃。

### U04 记录

左侧时间线、右侧当日摘要（窄屏纵向排列）。筛选为近 7 / 30 天、事件类型。每一项显示类型、时间、触发因素；备注通过展开查看。编辑/删除触发二次确认或短时撤销。空态不暗示“没有记录就是成功”。

### U05 SOS

沉浸式主卡：柔和圆形呼吸提示、90 秒倒计时、开始/暂停/跳过；下一阶段给 0–10 强度可选和 3 个行动建议。始终有「结束并离开」。尊重系统 reduced motion，静态文案也可完成步骤。没有惩罚性提醒和强制闭环。

### U06 计划

目标卡显示标题、状态和可编辑原因；三个小行动以复选项呈现，用户可新建、暂停和删除。完成行为增加当日已做计数，不产生虚构“生命值”。目标历史与事件历史分离。

### U07 洞察

7/30 天切换；顶部显示事件总数、记录天数、SOS 次数（均含统计期间与分母）。下方一张每小时柱状图及触发因素列表；样本量 < 5 时隐藏“主要触发”结论，显示“记录还少，先观察几天”。不把自述趋势解释为疾病改善。

### U08 日记

列表和编辑器并列；列表只显示日期、首行摘要；支持新增、保存、删除与取消。空态引导写下当下发生的事，不强制情绪标签。锁屏时标题、摘要与编辑内容全部隐藏。

### U09 屏蔽

顶部“第二阶段功能”状态可在原型中体验；两个浏览器连接卡明确「已连接/未连接/规则过期」。规则列表展示域名、时段、启用状态、添加；操作反馈区显示生效版本与最后同步时间。明确浏览器外及其他浏览器不受此页规则覆盖。

### U10 拦截页

这是扩展内页面，不复用桌面窗口导航。显示「这个页面已被你设定的规则拦下」，三个动作：返回原页、打开 SOS、申请暂停。不要显示完整敏感 URL，也不要出现羞辱性语言。扩展和桌面程序无法通信时 SOS 打开本地扩展简化引导。

### U11 暂停

弹窗显示等待时长、申请原因可选输入、倒计时；未结束不能确认。倒计时结束后明确选择 10 分钟或 1 小时，并确认“暂停只影响此浏览器的规则”。离开弹窗后计时持续；申请状态落盘。不存在伪装成强制约束的管理员权限。

### U12 设置与隐私

分组：外观、自动锁定、快捷键、备份与恢复、数据导出、清除数据、关于。危险操作分层、单独确认。设置页展示数据位置但隐藏路径中的用户隐私；更改自动锁定即时生效。

### U13 锁定

品牌及简单密码输入；不显示记录片段或统计。错误提示中性且限速；“忘记密码”解释本地加密不可恢复和新建空库的后果。锁定可不解锁进入不保存的 SOS 引导。

## 4. 状态与无障碍

- 页面覆盖加载、无数据、成功、可重试错误、锁定、扩展缺失、扩展失联、规则过期、备份损坏等状态。状态文案写“发生了什么＋下一步”，不能单写“失败”。
- 原型各导航按钮可点击，记录弹窗可输入、SOS 有状态转换、计划可勾选、洞察可切换、屏蔽可新增示例规则、暂停有倒计时、设置可切主题、锁定可模拟。正式实现须把原型的内存状态替换为 Rust 服务并满足 PRD 验收。
- `Tab`/`Shift+Tab` 顺序与视觉顺序一致，`Enter`/`Space` 可激活；弹窗焦点陷阱、Escape 关闭、打开弹窗时读屏标题。图表给可读数据替代文本；图形不是唯一信息载体。
- 首次安装无历史数据时不伪造统计。原型的虚拟数据均标注“演示数据”；评审时检查窄屏、深浅主题及系统减少动态效果。

## 5. Codex 实现映射

原型是交互与视觉合同，不含真实拦截、加密、数据库或医疗算法。实现时先建立设计令牌和导航壳，再按 U01→U13 的状态覆盖落实，保持文案与可访问性；测试按《01》验收场景执行。若技术限制需修改交互，先更新此文件和原型，避免代码与需求分叉。
