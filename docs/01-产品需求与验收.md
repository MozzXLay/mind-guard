# 净界｜Linux 本地行为重塑工具：产品需求与验收

版本：v0.1 · 2026-09-26 · 工作名：净界（MindGuard）

## 1. 产品定义

为希望调整色情内容使用、冲动性浏览或相关习惯的成年人提供离线、私密、非羞辱性的桌面工具。主循环是「觉察 → 暂停 → 选择 → 记录 → 回顾」。它不诊断或治疗勃起、射精、所谓“成瘾”，不承诺固定天数的生理恢复。自慰不默认视为失败，用户可只设定减少色情内容的目标。

设计参考“净心”的目标、记录和训练方向，采用独立名称、文案、布局、视觉元素和数据结构；不复制其图标、品牌、付费体系或内容。首发中文，Ubuntu 24.04 X11 优先；提供浅色和深色主题。应用单用户、离线优先，无账号、云同步、社区、遥测或默认网络请求。

## 2. 用户任务及范围

| 用户任务 | V1 对应能力 | 完成标准 |
| --- | --- | --- |
| 想明确自己要改变什么 | 首次引导、可编辑目标和提醒 | 可选择「减少浏览」「深夜避免浏览」「观察冲动」及自定义；不预选自慰禁令 |
| 冲动发生时需要片刻缓冲 | SOS 呼吸／倒计时／替代行动 | 两次 0–10 强度评分可跳过；任意一步可退出；退出也可保存未完成会话 |
| 快速记录发生了什么 | 记录弹窗、历史与编辑 | 事件、时间、触发因素和备注可选；单次操作目标 < 20 秒，允许补记与纠错 |
| 看出规律 | 近 7/30 天视图 | 有样本量、零数据空态、时间分布；避免小样本推断和“恢复百分比” |
| 保护私密内容 | 首次建库、解锁、自动锁定、备份 | 敏感事件/日记落盘前加密；可导出和恢复加密备份；清除操作二次确认 |
| 减少浏览入口 | 浏览器扩展及规则 | 第二里程碑；明确只覆盖已安装启用的浏览器/配置文件 |

### 非目标

- 医学诊断、疗效评分、色情内容自动识别、屏幕监控、键盘记录、云端账号。
- 系统级不可绕过的封锁或以 sudo 改写 DNS/hosts。
- 初版 AI 聊天、社区、会员付费、强制打卡或精液/睾酮等未经证实的指标。

| U13 | 锁定 | 解锁 | 限速重试；锁定期间遮盖其他应用页面与系统通知敏感信息 |

## 4. 核心流程与规则

### 首次启动

选择目标 → 设置主密码并确认 → 明确告知密码丢失无法恢复加密数据 → 创建加密本地存储 → 进入今日。首次引导不要求披露性行为，也不提供默认医疗推断。用户取消建库则退出，不产生敏感明文文件。

### 记录事件

事件类型：冲动、浏览、主动停止、自慰（可选开启显示）、替代行动。此处“自慰”只用于自我观察，不计作默认违约。触发因素多选：无聊、压力、孤独、焦虑、疲劳、睡眠不足、性欲、习惯、其他。每项皆可留空，只有类型与发生时间必填。时间按本地时区展示，数据层保留 UTC 时间和记录时区，跨时区后维持原事件日历归属。允许补记、编辑、删除；统计从事件重算。

### SOS

首页或快捷入口启动 → 可选输入强度 → 90 秒呼吸／静坐（可暂停或跳过）→ 可选再次评分 → 选择下一步行动／无需行动 → 保存。文本采用“现在先缓一缓”“想做哪一件小事”，没有“失败”“归零”等字样。若应用锁定，SOS 可打开不含个人历史的匿名界面；保存记录需解锁。全局快捷键可自定义；在 Wayland 等不支持环境显示不可用且保留托盘/应用内入口。

### 浏览器屏蔽（第二里程碑）

用户主动安装扩展并授权 → 扩展用原生消息宿主获取版本化规则 → 本地扩展存一份已生效规则 → 规则命中时转到扩展内拦截页。先支持精确域名和子域名匹配、允许列表、时间段；关键词拦截仅对明确受支持的 URL/搜索请求，不能承诺识别页面所有图像或内容。不要保存完整访问 URL 或标题；可选记一次匿名计数。宿主失联时继续使用最后一次规则并醒目提示“规则可能不是最新”；无规则时显示“未启用”。Firefox 与 Chromium 各自测试原生消息清单、规则 API 和重启行为。

暂停规则：默认等待 15 分钟，允许取消；时间结束后需再次确认，暂停 10 分钟 / 1 小时可选。更改系统时间、卸载扩展、换浏览器可能绕过；产品始终显示真实覆盖范围。无须管理员权限。

## 6. 可验证的非功能需求

- 常见页面在普通桌面机上打开无明显卡顿；建议目标：交互反馈 < 150ms，10 万事件的 30 天统计 < 2s；测试机器与样本需记录。
- 加密数据在首次写入前就受保护，包括 SQLite 主库、WAL、备份、日志、崩溃报告及导出过程；日志不得包含记录正文、URL 或密码。选择经维护的加密方案，明确密钥派生参数与迁移方案，不自行造密码学算法。
- 自动锁定默认 10 分钟，可选立即/5/10/30 分钟；锁屏不显示今日记录、日记或导航敏感计数；通知文案默认中性。
- 备份原子写入、校验后替换；恢复先验证版本与密码，再预览影响，随后替换并可回滚。导出成功后的文件位置可见。
- 键盘可访问全部控件，有焦点态、语义标签、可读对比度、减少动态效果；中文优先，窗口宽度 900–1600px 可用，最窄 720px 折叠侧栏。
- 遵循本地日期计算，但对系统时间倒退有提示；不把“连续天数”当唯一进步衡量。

## 7. 验收场景

1. 全新用户离线启动、建库、建立“减少色情视频”目标，未选择自慰约束，首页不出现自慰失败判定。
2. 新建一条昨晚 23:30 的浏览记录，附压力/疲劳，编辑为主动停止后，历史与 7/30 天统计同步更新。
3. SOS 开始后 30 秒点击跳过、再次评分留空并结束，记录为“已中断”，无错误结论。
4. 锁定后切换回应用、查看系统通知与最近使用视图，均无法读到敏感正文；正确密码解锁可读。
5. 备份、清空测试数据后恢复，数量与时间戳一致；密码错误不覆盖现有库。
6. 扩展关闭、宿主失联、换浏览器时，UI 不显示虚假的“全面生效”；已安装扩展的离线规则按设计持续。
7. 无事件 / 只有两条事件 / 十万条事件三组数据下洞察页显示正确分母与空态，不进行未经证实的健康推断。

## 8. 待产品验证的默认值

默认冷静期 15 分钟、备份提醒 30 天、自动锁定 10 分钟、SOS 90 秒和提醒默认关闭，均是可修改的产品假设，不是医学建议。正式实现前用自己的一周体验验证打断是否过多、是否形成过度自我监控。
